# 最初的仓库摘要

[作品集首页](README.md) · [研究过程](RESEARCH_PROCESS.md) · [证据索引](EVIDENCE_MAP.md)

本页保留最初仓库 README 中有用的研究范围、问题、方法、主题与局限，并整理为中英文平行页面。它是较早的公开摘要，**不是私有原始研究报告**。当前作品集提供更完整的分析。

## 研究概览

通过对两个游戏直播社群的探索性比较研究，考察观众参与、社群认同与变现实践。

## 研究问题

游戏品类、主播实践与社群动态如何影响观众的互动与参与？

## 研究方法

- 参与式观察
- 双案例比较分析
- 对已观察互动的定性解释

## 研究主题

- 社群角色与身份认同
- 观众互动与留存
- 变现机制与用户动机

## 研究局限

本探索性研究仅涉及两个案例，缺少平台后台数据及独立验证的人口统计资料。研究发现不能确立因果关系。

以上为研究主题，不代表测量过留存、验证过人口属性或证明过因果效应。更完整的限定与待补充记录详见[当前局限与伦理](LIMITATIONS.md)。
