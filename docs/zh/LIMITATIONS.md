## 方法局限

| 局限 | 对解释的影响 |
| --- | --- |
| 两个基于访问条件的案例 | 提供探索性深度，不是代表性研究或游戏品类的控制测试 |
| 参与程度不对称 | A 中的一手管理与内容讨论，不同于 B 中初期较浅的参与；运营论点依据不对称 |
| 生命周期阶段不同 | B 在观察开始时已成熟，A 的叙述涉及增长与退出，可能影响表面对照 |
| 无平台后台数据 | 礼物榜及可见会员等级不能核实收入、盈利、转化或留存 |
| 无核实的人口统计资料 | 头像、自填年龄、位置显示不能确认年龄、性别、收入、居住地或动机 |
| 观察覆盖未说明 | 未说明日期、时长、频率、漏看场次及记录方式，不能量化规律程度 |
| 非正式观众交流 | 日常聊天与其他平台交流提供了观众视角，但未按正式访谈程序招募、记录或分析，人数及覆盖范围待整理 |
| 来源记录时间不明确 | 已有报告但未提供底层田野记录，无法完整评估记忆、选择性注意与其他解释 |
| 内部参与者情感 | 作者承认对 A 有情感投入；维护其运营能力的判断可能影响对退场的解释 |
| 外部主张未核实 | 政策、自动化时间线、广泛品类经济和文献主张需要独立来源支持 |
| 适用边界有限 | 报告针对个人主播，明确不直接迁移至商家或认证商业账号；报告称其流量条件不同，但未验证 |

游戏情境、主播个人投入、运营策略、用户需求及关系机制可能共同影响社群发展。两个案例无法确定各因素的因果优先级。

## 理论与推断边界

准社会关系与社会交换是作者使用的分析视角，不是对这些观众心理状态的测量。报告的文献主张缺少完整一手出处；其有关归属感与打赏的跨文化解释保留为后续问题，不作为文化群体的事实。

非正式的其他主播对照、以角色解释观众及一次支持者韧性观察，均不是系统性比较样本，不能确立有关消费、性别、技术或关系韧性的普遍规则。

## 伦理考虑

**来源已记录的措施：** 报告声明已将主播及账号匿名化，移除账号标识、精确粉丝数及可定位内容标题。这是已记录的保护；不能据此声称获得正式同意、伦理审查或参与者验证。

**公开材料的匿名化处理：** 主播以案例 A、案例 B 称呼，排除主播与成员的直接身份标识。这可降低识别风险，但不能保证完全匿名。精确直播时间、特定角色或视觉品牌组合、详细地点、人口统计资料细节、可搜索引语及个人健康或生活状态推测均被省略或概括。私有报告未复制入仓库。公开的[证据索引](EVIDENCE_MAP.md)仅包含转述与章节位置。

## 拟议后续研究

以下是拟议活动，不是已完成方法或执行承诺。

| 问题或缺口 | 可能的下一步 | 有助评估什么 |
| --- | --- | --- |
| 证据来源 | 私下审阅既有记录，记录实际覆盖与来源 | 哪些论点为当时记录、回顾或二手信息 |
| 自我呈现与关系期待 | 通过自愿访谈理解观众如何看待主播公开的单身或恋爱状态 | 公开身份信号与亲密期待、信任及消费体验之间的联系 |
| 品类契合解释 | 观察更多对照或反例，采用可比覆盖并关注生命周期阶段 | 解释是否超出本案例对仍有适用性 |
| 安静陪伴 | 在适当同意下，进一步访谈活跃支持者和安静观看者 | 稳定在场是否有价值，选择性关注如何被体验 |
| 房管身份 | 询问持有者对认可、责任、自愿程度及负担的看法 | 选择效应与身份感知影响的区别 |
| 付费与个性化游戏互动 | 探索支持者对价值、期待与边界的叙述 | 可见行为是否支持所提出的交换机制 |
| 游戏角色偏好 | 不通过资料推测人口属性，探索偏好玩法与体验 | 角色选择是否关联期待的主播服务 |
| 跨文化方向 | 考虑独立比较中国与海外游戏社群，包括 Discord 等情境 | 相似概念在不同情境中是否有意义，不预设文化效应 |
